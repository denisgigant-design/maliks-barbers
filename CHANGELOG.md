# Malik’s Barbers · Cinematic Glass V2

This release places every file beside index.html. The tour fallback frames, animation library and Look Studio catalogue all use root-level filenames.

- Replaced Opening Hours, Booking and Pricing overlay artwork with three interactive smoked-emerald markers. Each marker follows the original measured wall track and becomes a direction control between viewpoints.
- Built three selectable HTML panels in faceted, shield and asymmetric shapes, with real background blur, small neutral reflections and a consistent white type treatment. The same material carries through to the shop directory.
- Added optional edge docking that considers the active wall, the barber and the available space. Portrait phones get internally scrollable drawers. Short landscape screens can use the space beside the portrait film.
- Connected all eight original services to a selectable menu. Skin Fade opens its matching Look Studio entry. The other named cuts are reference styles without additional prices.
- Added a lazy photographic Look Studio with four style selectors, keyboard navigation, previous/next controls, multi-angle dragging and an explicit return to Pricing. The studio keeps the room position and barber playback state.
- Centralized panel transitions and cancellation, bundled GSAP locally, and kept navigation on the original scroll and frame controller. Film failures can use stills taken at the actual camera stops.
- Extended Panels with separate desktop/mobile geometry, silhouette, blur, opacity, scale, edge lighting, motion duration, directional marker placement, full backup import/export and individual publishable presets.
- Separated the existing barber runtime from the exported panel data. The original two alpha playback paths, floor shadow, size, depth, layer order, editor docking and lighting/keyframe tools remain available.
- Limited the optional material shader to a small glass edge drawn on interaction. Touch and low-power paths use CSS. The selected tour loads on entry. Barber media and studio photography load when their features are used.

## Asset notes

The red “Malik’s” lettering on the greenery wall and the storefront lettering are part of the original camera imagery. The three navigational neon overlays have been removed from the interface.

The source includes no approved haircut photographs or complete 3D mannequin with haircut geometry. The gallery supports real photographs and multiple angles. Its initial empty slots are identified in the interface. The original shop photograph has its own caption. Instructions for supplying photographs are in UPLOAD-FIRST.txt.
