USE
1. Open the website on your phone or desktop and navigate to PRICING.
2. Tap "Panels", then choose "Pricing & services" in the panel selector.
3. A "Barber video placement" editor appears IMMEDIATELY BELOW the selector.
4. Left/right, up/down, 4 arrow nudge buttons, size, depth, layer order,
   shadow strength and on/off control are available.
5. Controls save locally on the device. Both Desktop and Mobile can be edited
   using the "Preset to edit" selector (live preview only on matching device).
6. Tap "Export barber-preset.js". This exports BOTH mobile and desktop
   placement values. Replace barber-preset.js on GitHub with the downloaded file
   to make the positions public for all visitors.
